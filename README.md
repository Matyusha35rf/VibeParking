# Разводка — парковки Петроградского района

Карта парковок Петроградского района Санкт-Петербурга. Вводите адрес или выбираете станцию метро и видите парковки рядом: бесплатные, платные, с неизвестной оплатой и закрытые, с расстоянием и маршрутом в Яндекс Картах.

## Как устроено

- `index.html` — вся страница: Leaflet + OpenStreetMap, без сборки и бэкенда.
- `parkings.js` — локальная выгрузка 917 парковок (`amenity=parking`) из OpenStreetMap на 26.10.2026.
- Поиск адреса идёт через геокодер Nominatim, а подложка карты — через тайлы OSM. Для них нужен интернет.

## Запуск

Это статический сайт: подходит любой хостинг статики (Vercel, GitHub Pages) или локальный сервер в папке проекта. Если открыть `index.html` двойным кликом, браузер может не подгрузить `parkings.js`.
